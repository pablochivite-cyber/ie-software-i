# ie-software-i

Calculadora básica de línea de comandos en Python. Proyecto creado con `uv init`.

## Requisitos

- Python 3.13 o superior
- [uv](https://docs.astral.sh/uv/)

## Uso

```bash
uv run calculator.py
```

La calculadora pide un número, un operador (`+`, `-`, `*`, `/`) y otro número, y muestra el resultado. Escribe `salir` para terminar.

## Archivos

- `calculator.py`: implementación de la calculadora.
- `main.py`, `pyproject.toml`, `.python-version`, `.gitignore`: archivos generados por `uv init`.
